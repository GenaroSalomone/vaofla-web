# vaofla-web

Sitio estatico publicado desde el repo privado `vaofla` (F8). Este repo
contiene EXCLUSIVAMENTE la salida de `pnpm build` — nunca datos crudos,
catalogo o nombres reales. Se publica con `scripts/publish-web.sh` desde el
repo privado; no se edita a mano.

Runbook: ver `docs/runbook.md` en el repo privado.
